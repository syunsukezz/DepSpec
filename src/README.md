# Depspec
## 概要
打鍵圧を制御してゴールまで進もう！
Depspecは文字から文字にジャンプして進むアクションゲーム.君の指に込められた力がそのままジャンプ力となり，着地の衝撃となる．
## ステージギミック
### 障害物エリア
- キーを打つとプレイヤーは一定距離をジャンプする．
- キーを打つ強さによって，ジャンプする高さが変わる．
- ハードルのようにランダムな高さがある障害物をジャンプする高さを調節することによってクリアしていく．
- 上から生えている障害物によって高すぎても障害物に当たってしまう設計
- 障害物に当たったら，当たった障害物の手前でリスポーン
- キーを押し間違えたらジャンプできない
### 谷のエリア
- キーを打つとプレイヤーは一定高度でジャンプする
- キーを打つ強さによって，ジャンプする距離が変わる．
- 地面に空いているランダムな大きさの穴をジャンプによって越えて行く
- 穴に落ちたら穴の手前の陸地にリスポーン
- キーを押し間違えたらジャンプできない
### 落下物のエリア
- キーを打つとプレイヤーは一定間隔で落ちているドーナツや木箱，金床に飛び乗る．
- 落下物の硬さは ドーナツ<木箱<金床 で，キーを打つ強さが弱すぎると落下物を破壊できない．
- キーを打つ強さが強すぎると落下物を破壊して地面に触れた瞬間に潰れて手前の落下物があった位置にリスポーンする，同時にプレイヤーが潰された地点の落下物が復活する
- キーを押し間違えたらジャンプできない
### 坂のエリア
- キーを打つとキーを打つ強さに応じた高さの橋桁が下から伸び，現在地点から曲線で結ばれる．
- プレイヤーは曲線を滑り輪をくぐるとスコアが足される．
- キーを押し間違えたら何も起こらない
